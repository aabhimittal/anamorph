Why the stochastic model matters

Photon shot noise is skewed, so the Gaussian tail is wrong

At low dose, acid counts follow a compound Poisson distribution. A Gaussian with the same mean and variance gets the tails wrong, and in opposite directions. Bridges (resist that should stay dark prints) live in the upper tail, which the Gaussian under-predicts by up to 35× here. Breaks live in the lower tail, which it over-predicts. anamorph's saddlepoint tail uses the exact cumulant generating function and stays inside the Monte-Carlo confidence interval.

What this page is and is not
  • The scanner and resist numbers are an illustrative High-NA card from public literature, not calibrated to any tool. Absolute P_fail values are model-relative.
  • The browser uses the 24 strongest of the engine's SOCS kernels (aerial error ≤ 0.0075 against the full 0.995-energy set). On load it checks itself against the engine at 48 pixels per clip.
  • Thin-mask optics only: 3D mask effects need a rigorous reference that is not built yet.
  • Source: github.com/aabhimittal/anamorph. Regenerate the data with python demo/build_data.py.
